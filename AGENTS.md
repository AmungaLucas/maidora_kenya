This is the Maidora Kenya mobile app — an Expo/React Native application.

## Navigation — MANDATORY

- Use **React Navigation** (`@react-navigation/native` + `@react-navigation/native-stack`) for ALL navigation.
- **NEVER introduce expo-router, react-router, or any file-based routing.** This is a hard product decision by the owner.
- App entry is `index.ts` → `registerRootComponent(App)` (no `src/app/` route directory).
- Screens live in `src/screens/`, registered in `src/navigation/RootNavigator.tsx`.
- Current stack: `Splash` (H07 Ping Letters) → `Home` via `navigation.replace`, so back never returns to splash.

## Brand system — locked decisions (do not change without the owner)

| Context      | Asset                          |
|--------------|--------------------------------|
| General load | 01 TwinArcs (`BrandLoader variant="twinArcs"`) |
| Button load  | 03 Radar (`variant="radar"`)   |
| Full-screen  | 03 Radar (`FullScreenLoader`)  |
| Splash       | H07 Ping Letters (`src/screens/SplashScreen.tsx`) |

- Palette + fonts: single source of truth in `src/theme/theme.ts`
  (brand #214E3B, brandSoft #7BC08B, cream #F7F3E9, gold #D6A64F, Poppins).
- Logo geometry is the original 720×680 SVG paths in `src/components/brand/BrandMark.tsx` — never redraw.

## Commands

```bash
bunx expo install <package>   # ALWAYS use for new deps — resolves SDK-compatible versions
bunx expo start               # dev server
bunx tsc --noEmit             # typecheck
bunx expo-doctor              # dependency/config diagnosis
```

Run typecheck before declaring any task done.

## Rules

- Expo SDK 58 / React Native 0.88 / New Architecture. Reanimated 4 (worklets auto-configured — do NOT add `react-native-reanimated/plugin` to babel manually).
- If `ios/` and `android/` do not exist they are generated by CNG — never create or edit them by hand; configure via `app.json` / config plugins.
- Native modules beyond the Expo bundled set require a development build (`expo run:android|ios` or `eas build`), not Expo Go.
- Keep components small and composed under `src/components/`; screens wire them together.
